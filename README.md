# 刷题系统

> 纯前端在线刷题应用 · 零依赖 · 离线可用 · 数据本地存储 · 支持自定义题库

**在线访问**：https://xgyx-02.github.io/

一个通用的刷题/自测系统：内置通信原理课程题库（70 题），同时支持 PDF 导入题目和手动添加自定义题目，适配任意学科的复习场景。所有数据保存在浏览器 localStorage 中，无需服务器、无需登录。

## 快速开始

- **在线使用**：直接访问 https://xgyx-02.github.io/
- **本地使用**：双击 `index.html` 即可在浏览器中打开，无需安装任何软件

## 功能特性

### 刷题核心
- **四种题型适配**：单选（点击选项即答）、多选（勾选后提交）、判断（对/错按钮）、计算题（多行公式输入，关键词模糊判分）
- **多种练习入口**：顺序练习 / 随机练习 / 按题型专项（单选、多选、判断、计算）/ 薄弱题目专项（自动汇总答错与低正确率题）
- **答题卡**：题号网格一览已做/未做状态，点击任意题号跳转
- **滑动切题**：触屏设备左右滑动即可切换上一题/下一题
- **中断续刷**：练习进度自动保存，中途关闭页面后再次进入可恢复现场；完成后自动结算清空
- **完成总结**：一套题刷完自动弹出成绩单（答对/答错/正确率/用时）
- **快捷键**：`1-9` 单选答题、`Z/X` 判断、`Enter` 计算题提交、`←→` 切题、`Space` 显示/隐藏答案（可在设置页关闭）

### 题库管理
- **在线编辑器**：可视化管理三类题目来源（内置 / PDF 导入 / 自定义），支持新增、编辑、删除、按来源和题型筛选
- **PDF 导入**：选择 PDF 文件自动提取文字并解析题目，预览确认后入库，自动跳过重复题，导入失败给出具体原因
- **自定义题目**：手动添加任意题型的新题，与内置题库合并参与刷题

### 数据与统计
- **统计看板**：总题量、已做题数、正确率、总分、错题数、薄弱题数一目了然
- **错题本**：完整题干展示，支持多维筛选、排序、批量管理，可批量导出题目文本
- **作答历史**：每道题可查看历史作答记录
- **数据备份**：一键导出全量 JSON / 复制备份文本 / 粘贴导入恢复，方便换设备迁移

### 界面
- **深色模式**：完整适配夜间护眼，题图自动降亮度
- **响应式布局**：桌面端顶部导航栏 + 移动端底部标签栏，覆盖手机到宽屏
- **打印支持**：`Ctrl+P` 打印时自动隐藏交互控件，仅保留题目内容
- **玻璃拟态 UI**：CSS 变量统一管理配色，浅色/深色双主题

## 数据存储说明

所有数据存储在浏览器 localStorage 中，按用途分片：

| Key | 内容 |
|-----|------|
| `csp_config` | 全局配置（主题、计时、计分、刷题行为等） |
| `csp_records` | 答题记录（每题答对/答错次数、历史） |
| `csp_records_archive` | 归档的旧答题记录（可恢复） |
| `csp_errors` | 错题 ID 列表 |
| `csp_timer` | 总计时、单题用时、超时记录 |
| `csp_cache` | 题库缓存（版本更新后自动刷新） |
| `csp_imported` | PDF 导入的题目 |
| `csp_custom` | 手动添加的自定义题目 |
| `csp_session` | 进行中的练习会话（用于中断续刷） |

## PDF 导入说明

支持的题目格式（文本型 PDF）：

1. 题目以数字编号开头（如 `1.`、`12、`）
2. 单选题含 `A.` `B.` `C.` `D.` 选项行
3. 判断题含"（ ）"或题干中有"对/错"字样
4. 计算题含"计算"“求解"等关键词或含公式表述
5. 扫描版（图片型）PDF 无法提取文字，暂不支持

导入时可指定题目归属章节；PDF 内若有"第X章"标题则自动识别覆盖。
